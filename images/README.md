# Image Templates

This directory contains OS-specific Packer templates organized by OS and CIS level:

- windows/cis1 and windows/cis2
- ubuntu/cis1 and ubuntu/cis2
- rhel/cis1 and rhel/cis2
- azurelinux/cis1 and azurelinux/cis2

Each CIS Level 2 template applies additional controls on top of Level 1.
